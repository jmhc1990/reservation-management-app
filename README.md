# 📅 StyleSync - Gestión de Reservas e Inventario

[![Flutter](https://img.shields.io/badge/Flutter-02569B?style=for-the-badge&logo=flutter&logoColor=white)](https://flutter.dev/)
[![Firebase](https://img.shields.io/badge/Firebase-FFCA28?style=for-the-badge&logo=firebase&logoColor=black)](https://firebase.google.com/)
[![Dart](https://img.shields.io/badge/Dart-0175C2?style=for-the-badge&logo=dart&logoColor=white)](https://dart.dev/)

**StyleSync** es una aplicación móvil multiplataforma diseñada para la gestión integral de reservas, administración de servicios y control de inventario en tiempo real. Este proyecto ha sido desarrollado como trabajo final para el Ciclo Superior de Desarrollo de Aplicaciones Multiplataforma (DAM).

---

## 🚀 Características Principales

* **Gestión de Reservas:** Sistema ágil para agendar, modificar y cancelar citas con actualización en tiempo real.
* **Control de Inventario:** Panel de administración para monitorizar stock y recursos de manera eficiente.
* **Seguridad y Roles:** Implementación de Firebase Authentication para acceso seguro y gestión diferenciada (Admin vs. Usuario).
* **Persistencia en la Nube:** Sincronización inmediata de datos mediante Cloud Firestore.
* **UI/UX:** Interfaz intuitiva y moderna prototipada en [Figma](https://www.figma.com/design/Uo8QEWR8LchOKp1LqZrizK/StyleSync-Design-System?node-id=0-1&t=QNwzcLZfKBrV0e7o-1).

## ⚙️ Configuración del Proyecto

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/jmhc1990/reservation-management-app.git⁠
    ```

2.  **Instalar dependencias:**
    ```bash
    flutter pub get
    ```

3.  **Configuración de Firebase:**
    * Asegúrate de colocar tus archivos `google-services.json` (Android) y `GoogleService-Info.plist` (iOS) en las carpetas correspondientes.

4.  **Ejecutar la aplicación:**
    ```bash
    flutter run
    ```
