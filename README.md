# 📅 Reservation Management App

## 📝 Descripción
Esta aplicación es una solución móvil diseñada para la gestión eficiente de reservas. Permite a los usuarios gestionar citas, disponibilidad y seguimiento de recursos en tiempo real, ofreciendo una experiencia fluida y escalable.

## 🚀 Tecnologías Utilizadas
* **Lenguaje:** Dart 💙
* **Framework:** Flutter 💙
* **Backend:** Firebase (Firestore, Auth) 🔥
* **Gestión de Estado:** [Ej: Provider, Bloc, Riverpod] 🏗️
* **Testing:** flutter_test 🧪

## ✨ Características Principales
* **🔐 Autenticación:** Sistema de usuarios seguro con Firebase Auth.
* **📋 Gestión de Reservas:** Operaciones CRUD completas para reservas.
* **📱 Interfaz:** Diseño responsivo basado en Material Design.

## 🛠️ Requisitos Previos
* [Flutter SDK](https://docs.flutter.dev/) instalado.
* Emulador configurado (con virtualización habilitada en BIOS).
* Firebase CLI configurado.
